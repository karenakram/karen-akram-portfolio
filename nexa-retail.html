Nexa Retail — Sales Performance Dashboard

An end-to-end retail analytics project: documented data cleaning followed by a multi-page Power BI report.

Project Overview

Nexa Retail is a fictional retail dataset used to practice a full analytics workflow. The project covers data cleaning with a documented cleaning log, followed by an interactive multi-page Power BI report with pages for the main dashboard, sales performance, customer analysis, product & inventory analysis, and returns analysis.

Power BIPower QueryDAXExcel

Business Problem

Retail managers need a single, reliable view of performance — sales trends, customer behavior, inventory health, and return reasons — instead of scattered spreadsheets that are hard to trust and hard to read.
